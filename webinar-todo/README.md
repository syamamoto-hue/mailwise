# Webinar ToDo 管理アプリ

毎月開催するウェビナーの準備タスクを管理する社内向け Web アプリです。
Google スプレッドシートの一覧性を残しつつ、**開催日からの逆算で日付を自動計算**し、毎月の複製・進捗管理をしやすくしています。

- **Next.js (App Router) + TypeScript + Tailwind CSS**
- **SQLite + Prisma**（ローカルファイル DB）
- **date-fns**（日付計算）/ **papaparse**（CSV）
- ログイン機能なし（社内利用想定／後から追加できる構成）

---

## 1. 日付計算ロジック（重要）

各タスクは絶対日付ではなく「**開催日の何日前か**」（オフセット日数）で管理します。

```
着手日 = 開催日 − 着手オフセット日数 (startOffsetDays)
期日   = 開催日 − 期日オフセット日数 (dueOffsetDays)
```

- CSV 取込時は、開催日と各タスクの着手日・期日から
  `offset = differenceInDays(開催日, タスク日付)` でオフセットを自動計算します。
- 開催日を変更したり、テンプレ／複製で新しい月を作ると、
  オフセットをもとに**全タスクの日付が自動で再計算**されます。
- 例：開催日 `2026-07-29`、期日オフセット `7` → 期日 `2026-07-22`。
  翌月 `2026-08-28` に複製 → 期日 `2026-08-21`。

### 着手日・期日を手動変更したとき

タスクの日付を手で変更すると、反映範囲を選べます。

1. **このウェビナーだけ変更**：`isManuallyOverridden = true` として記録。
   以後、開催日変更で再計算されても**この日付は維持**されます。
2. **今後のテンプレートにも反映**：開催日から逆算してオフセットを更新し、
   紐づくマスターテンプレート（`parentTemplateTaskId`）のオフセットも書き換えます。

## 2. セットアップ手順

> Node.js 18.18 以上（推奨 20 以上）が必要です。

```bash
cd webinar-todo
npm install
```

### DB 初期化（スキーマ作成 + サンプル投入）

```bash
npm run db:reset
```

`db:reset` は次を行います。

- SQLite DB（`prisma/dev.db`）を作成
- マスターテンプレート 83 件を投入（添付 CSV ベース）
- デモ用ウェビナー（2026-07-29）を 1 件作成
- 取り込みテスト用のサンプル CSV を `sample-data/webinar-2026-07-29.csv` に生成

スキーマだけ反映したい場合は `npm run db:push`、シードのみは `npm run db:seed`。

### 起動方法

```bash
npm run dev          # 開発サーバー http://localhost:3000
# 本番ビルドで動かす場合
npm run build && npm start
```

DB の中身を GUI で確認したいときは `npm run db:studio`（Prisma Studio）。

## 3. CSV インポート方法

`CSV取込 / 書出` 画面（`/import`）で行います。

1. CSV ファイルを選択、またはテキストを貼り付け
2. 取込モードを選択
   - **新規ウェビナーとして取込**
   - **既存ウェビナーに上書き**（対象ウェビナーを選択）
   - **マスターテンプレートとして取込**
3. 「年の補完」は、日付が `7月29日` のように年を含まない場合に使用します
4. 「取り込む」を押すと、開催日・各日程・タスク・カテゴリ・担当者・ステータス・工数・着手日・期日・備考を自動判定し、オフセットも自動計算します

> Google スプレッドシートの書き出し CSV（先頭に空列がある形式）に対応しています。
> 動作確認には `sample-data/webinar-2026-07-29.csv` を使えます。

### CSV エクスポート

各ウェビナー詳細の「CSV書出」または `/import` 画面の一覧から書き出せます。
項目：大カテゴリ / 中カテゴリ / 小カテゴリ / 会社 / 担当者 / ステータス / 工数（日数）/ 着手日 / 期日 / **完了日** / 備考。
Excel 文字化け防止のため UTF-8 BOM 付きで出力します。

## 4. 主要ファイル構成

```
webinar-todo/
├─ prisma/
│  ├─ schema.prisma          # Webinar / Task / TaskTemplate モデル
│  └─ seed.ts                # マスターテンプレ + デモ + サンプルCSV生成
├─ sample-data/
│  └─ webinar-2026-07-29.csv # 取込テスト用（seedで生成）
├─ src/
│  ├─ lib/
│  │  ├─ dates.ts            # オフセット⇔日付の計算、日本語日付パース
│  │  ├─ csv.ts              # CSVパース / エクスポート
│  │  ├─ stats.ts            # 進捗・期限超過・担当者別の集計
│  │  ├─ status.ts           # ステータスの色分け
│  │  ├─ webinarService.ts   # テンプレ生成 / 複製 / 再計算
│  │  ├─ prisma.ts / serialize.ts / types.ts
│  ├─ app/
│  │  ├─ page.tsx            # ① ダッシュボード
│  │  ├─ webinars/page.tsx   # ② ウェビナー一覧
│  │  ├─ webinars/[id]/page.tsx  # ③ ウェビナー詳細 + ④ タスク一覧
│  │  ├─ calendar/page.tsx   # ⑤ カレンダー
│  │  ├─ templates/page.tsx  # ⑥ マスターテンプレート管理
│  │  ├─ import/page.tsx     # ⑦ CSV取込 / 書出
│  │  └─ api/                # REST API (webinars / tasks / templates / import / export)
│  └─ components/            # 画面ごとのクライアントコンポーネント
```

### 画面構成

1. **ダッシュボード** … 直近ウェビナーの開催日・残り日数・全体進捗・未着手/着手中/完了・期限超過・今日着手・1週間以内が期日・担当者別
2. **ウェビナー一覧** … タイトル / 開催日 / ステータス / 完了数・進捗率 / 期限超過 / 今日 / 担当者別未完了
3. **ウェビナー詳細** … 重要日程の編集、開催日変更での自動再計算、進捗、削除
4. **タスク一覧** … スプレッドシート風に直接編集（全タスク / 大カテゴリ別 / 担当者別 / ステータス別 / 期限順 / 今日やる / 期限超過の切替）、追加・削除・複製・並び替え、ステータス色分け、完了日記録
5. **カレンダー** … 着手日（開始）と期日（期限）を月表示。完了は控えめ、期限超過は強調
6. **マスターテンプレート管理** … オフセット日数ベースでタスク定義を編集
7. **CSV取込 / 書出**

## 5. データ設計

`Webinar` / `Task` / `TaskTemplate` の 3 モデル（`prisma/schema.prisma`）。
日付は `yyyy-MM-dd` の文字列で保持しています。仕様書の型定義に準拠しています。
