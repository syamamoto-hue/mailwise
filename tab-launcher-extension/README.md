# プリセットタブランチャー（Chrome拡張機能）

「プリセット → クライアント（歯科など）を選ぶ → 関連URLをまとめて新しいタブで開く」拡張機能です。
開いたタブは、クライアント名のついた**タブグループ**に自動でまとまります。

```
[ツールバーのアイコンをクリック]
        ↓
   プリセットを選ぶ（例：BRAIN定期報告）
        ↓
   クライアントを選ぶ（例：歯科A）
        ↓
   そのクライアントのURLが新しいタブでまとめて開く
```

---

## 1. インストール手順（初回だけ）

1. このフォルダ（`tab-launcher-extension`）を、自分のパソコンにダウンロードして保存します。
   - GitHubから「Code」→「Download ZIP」で落として解凍するのが簡単です。
2. Chromeのアドレスバーに `chrome://extensions` と入力してEnter。
3. 画面右上の **「デベロッパーモード」をオン**にします。
4. 左上に出てくる **「パッケージ化されていない拡張機能を読み込む」** をクリック。
5. 保存した `tab-launcher-extension` フォルダを選びます。
6. ツールバーにアイコンが出れば完了です。（パズルのピース型アイコン🧩を押すと固定できます）

> 古い拡張機能が残っている場合は、混乱を避けるため `chrome://extensions` で削除しておくと安心です。

---

## 2. 使い方

### タブを開く
- ツールバーのアイコンをクリック → プリセットを選ぶ → クライアントを選ぶ。
- 選んだクライアントのURLがまとめて開き、タブグループになります。

### プリセットやクライアントを登録する
- アイコンを押して出るメニューの右上 **「⚙️ 設定」** をクリック（または `chrome://extensions` のこの拡張機能の「詳細」→「拡張機能のオプション」）。
- 設定画面で次のことができます。
  - **プリセットの追加・名前変更・削除**（左側）
  - **クライアントの追加・削除**（右側）
  - クライアントごとに **タブグループの色** を選択
  - **URLを1行に1つずつ** 貼り付け（5個でも10個でもOK）
- 入力した内容は**自動保存**されます。

### バックアップ
- 設定画面右上の「⬇ バックアップ書き出し」でJSONファイルとして保存できます。
- 別のPCや再インストール時は「⬆ 読み込み」で元に戻せます。

---

## 3. ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の基本設定 |
| `popup.html` / `popup.js` | アイコンを押したときのメニュー（プリセット→クライアント選択） |
| `options.html` / `options.js` | 設定画面（プリセット・クライアント・URLの編集） |
| `common.js` | データの保存・読み込みなどの共通処理 |
| `style.css` | 見た目 |

データはお使いのChrome内（`chrome.storage.local`）に保存されます。
